# Prompt inicial pro Claude Code

Cole no Claude Code, na pasta do projeto, depois de copiar os arquivos deste kit (CLAUDE.md, SPEC.md, PLAN.md e assets/) pra raiz.

---

Leia CLAUDE.md, SPEC.md e PLAN.md inteiros antes de fazer qualquer coisa. Este é o novo portfólio gustavodev.dev, one page, React + Vite + TS + Tailwind + GSAP (com Draggable, Inertia, Physics2D) + Lenis. Tudo no site tem física: mola, inércia, quique, skew por velocidade. Sem quebra em blocos na seção de projetos.

Execute só a Etapa 0 do PLAN.md: scaffold do projeto, fontes locais, tokens de cor, Lenis, grain e grade, SEO/OG completos no index.html, estrutura de pastas do CLAUDE.md, assets copiados pra public, e a página preta com o HUD nos quatro cantos funcionando (hora real de Palmas, coordenadas, seção atual, status com ponto piscando).

Regras que não se negociam nesta e em todas as etapas: nenhuma serifa, nenhuma fonte via CDN, nenhum hex solto fora de tokens.css, nenhuma palavra que remeta a museu ou galeria na tela, nenhum travessão em texto, textos sem frase de efeito. Mobile-first só com min-width.

Ao terminar, rode npm run dev, me diga o que conferir no navegador e pare. Não avance pra Etapa 1 sem eu aprovar.
